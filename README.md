# taken.

### AI agent infrastructure for browser-based trading workflows

[Website](https://taken.trade) · [Open the app](https://app.taken.trade) · [Contact](mailto:contact@taken.trade)

Taken is building tools that connect AI agents to browser-based trading workflows, with account connections, developer APIs, MCP, and user controls.

## What we're building

- Browser automation for supported workflows.
- Connected-account and saved-workflow management.
- REST API and Model Context Protocol (MCP) integrations for developers.
- A Chrome companion for browser workflows.
- Controls to pause tasks, take over manually, and cancel automation.

## Project status

Taken is under active development. Features and integrations may change. Availability depends on the supported platform and configuration; a product description does not imply that live order execution is available. Check the application for current capabilities.

This repository contains product information. Application source code and operational infrastructure are maintained privately.
