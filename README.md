# taken.

### AI infrastructure for trading workflows

[Website](https://taken.trade) · [Open the app](https://app.taken.trade) · [Documentation](https://taken.trade/docs) · [Contact](mailto:contact@taken.trade)

Taken is building the connection between AI agents and the trading platforms people use. The product brings browser workflows, connected accounts, and developer integrations into one place, with controls that let users watch, pause, take over, and cancel tasks.

## The problem

Many trading workflows still happen through interfaces designed for people: navigating websites, switching accounts, and repeating steps across platforms. Connecting an AI agent to those workflows requires more than a prompt. It needs a way to interact with the platform, respect account boundaries, and return control to the user.

Taken's goal is to provide that infrastructure for traders, AI developers, and fintech builders.

## What we're building

| Product area | Purpose |
| --- | --- |
| Browser workflows | Turn natural-language instructions into tasks on supported sites. |
| Connected accounts | Manage supported account connections and saved workflows. |
| Developer integrations | Connect external applications and agents through REST APIs and Model Context Protocol (MCP). |
| Chrome companion | Bring supported workflows into the user's browser. |
| User controls | Observe progress, pause automation, take over manually, and cancel tasks. |

## How it works

1. Open Taken and choose an available workflow or supported connection.
2. Give the agent an instruction.
3. Watch the task and use the available controls to intervene when needed.

For integration details, start with the [documentation](https://taken.trade/docs).

## Project status

Taken is under active development. Features and platform support depend on the current release and configuration. The application currently states that trading and payment actions are blocked and no orders are submitted. This overview does not represent live order execution as an available capability.

This repository contains product information and security-reporting guidance. Application source code, operational infrastructure, and internal development history are maintained privately.

## Direction

Development is focused on broader supported workflows, clearer developer integrations, and stronger user controls. Any future live execution capability requires platform-specific validation and explicit authorization. Roadmap direction is not a promise of availability or a release date.
