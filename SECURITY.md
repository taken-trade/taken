# Security reports

Report suspected vulnerabilities privately to [contact@taken.trade](mailto:contact@taken.trade).

Start with a short description of the affected feature, impact, and reproduction steps using a test account. Request a secure channel before sending sensitive evidence. Never send passwords, API keys, access tokens, customer records, or saved browser-session data in an issue or initial email.

This repository contains product information only. Reports about the hosted application are welcome through the private contact above.
